Install on your phone

  1. Make sure your phone is on the same Wi-Fi as this computer.
  2. Tap the Download button above from your phone's browser.
  3. Open the downloaded file. Android will ask to allow installing from this source — allow it for your browser app, once.
  4. If Void is already installed from an earlier test, uninstall it first (long-press the icon → Uninstall), then install this one fresh. Updating in place can leave Android's launcher showing the old cached icon.
  5. Tap Install, then Open. If you had Void open in your recent apps already, swipe it away first — reopening a backgrounded app skips the loading screen since it doesn't restart.
